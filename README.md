# Medical Diagnosis Center by Service Portal (ServiceNow)

## Project Overview

The Medical Diagnosis Center is a web-based application developed using ServiceNow and Service Portal. It simplifies patient registration, medical test booking, appointment management and lab report generation through a user-friendly portal.

## Technologies Used

* ServiceNow Platform
* Service Portal
* JavaScript
* HTML, CSS and AngularJS
* Business Rules and Client Scripts
* GlideRecord
* Flow Designer

## Key Features

* **Patient Registration:** Patients can register and manage their information.
* **Test Booking:** Patients can browse available diagnostic tests and book appointments.
* **Appointment Management:** Patients can track their bookings and cancel appointments.
* **Lab Reports:** Automatically generates reports when diagnostic tests are completed.
* **Admin Dashboard:** Administrators can monitor appointments, reports and diagnostic activities.
* **Email Notifications:** Sends appointment confirmations to patients.

## Project Modules

1. Medical Test Catalog
2. Patient Registration
3. Appointment Booking
4. My Appointments
5. Lab Reports
6. Admin Dashboard

## How to Install

1. Log in to your ServiceNow instance.
2. Navigate to **All → System Update Sets → Retrieved Update Sets**.
3. Click **Import Update Set from XML**.
4. Upload the XML file available in this repository.
5. Preview the imported update set and resolve any reported issues.
6. Commit the update set.
7. Open the Medical Diagnosis Center Service Portal.

## Project Objective

To develop a centralized diagnostic management system that reduces manual work, simplifies medical test booking and improves appointment and lab report management.
